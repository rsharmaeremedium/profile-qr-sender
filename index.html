How this works & browser limits
  1. Add the email IDs in step 1. The app extracts every valid address and removes duplicates.
  2. For each email, click Search admin. The Medxplain admin opens with the email pre-filled (log in if needed).
  3. Open the user, copy the URL from the address bar (it contains /usersprofile/<id>/), and paste it into the row. A bare numeric ID also works. The app converts it to https://medxplain.eremedium.in/medxplain/<id>/.
  4. Click Open to confirm the profile URL loads, then download the PNG or tap Share.

Why not fully automatic? The admin is login-protected and on a different origin. A browser PWA is not allowed to read that page's HTML, so the lookup step stays assisted. Everything after that — URL building, QR generation, file naming, ZIP export and sharing — runs locally in this app. No data is uploaded anywhere.
